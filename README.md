# Cloud-Integrated Journaling Platform

A lightweight web application built to securely capture, store, and retrieve user journal entries, featuring real-time data persistence and user authentication.

### 📈 Project Roadmap & Backlog
* **Origin:** Developed during middle school (6th/7th grade) as a practical deep-dive into backend cloud environments.
* **Current Status:** Retained as a foundational portfolio piece demonstrating database integration.
* **Next Steps:** Planning a 3–4 month software revision phase to modernize the JavaScript syntax, optimize the database rules, and update the Firebase configurations.
